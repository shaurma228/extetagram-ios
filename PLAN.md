# План разработки

## 1. Подтвердить базовую сборку

- Довести проверочный запуск до публикации IPA. При ошибке исправить первый упавший шаг и повторить сборку.
- Сверить результат автоматических проверок содержимого IPA в GitHub Actions.
- Установить IPA через SideStore на настоящий iPhone, запустить приложение и повторно открыть его после закрытия.
- Зафиксировать модель устройства, версию iOS, номер запуска и обнаруженные проблемы.
- Этап завершён, когда IPA устанавливается и приложение стабильно открывается повторно.

## 2. Проверить работу Telegram

- В приватном репозитории настроить собственные ключи Telegram API и собрать вариант с включённым входом.
- Проверить вход на iPhone, отправку и получение сообщений в тестовом чате.
- Закрыть и снова открыть приложение, убедиться в сохранении сессии и истории.
- Этап завершён, когда эти сценарии проходят на устройстве с подтверждённой сборкой.

## 3. Выпустить небольшой MVP

- Добавить раздел расширенных настроек с понятной навигацией и сохранением выбранных параметров.
- Внести небольшие полезные изменения в список чатов, сохранив основные сценарии общения Telegram-iOS.
- Проверить настройки и список чатов на iPhone, включая перезапуск и обмен сообщениями.
- После базовых сценариев добавить экспорт выбранных сообщений в изображение, если он укладывается в объём MVP.
- Этап завершён, когда изменения доступны в установленной сборке и не мешают входу и переписке.

## 4. Поддерживать обновления

- Держать изменения относительно Telegram-iOS изолированными и проверять их применимость при обновлении закреплённой версии.
- Для каждого обновления повторять сборку и ключевые проверки на устройстве, включая вход, переписку и сохранение данных.
- Фиксировать совместимость и известные ограничения каждой проверенной версии.

## Отдельное решение

- Поддержку Python-плагинов Android рассмотреть отдельно после MVP. Сначала определить совместимость, ограничения iOS и ожидаемую пользу, затем принять решение о реализации.
