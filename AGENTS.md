# Правила работы агентов

- Ведущий ассистент работает как оркестратор: разбивает задачу на независимые, чётко ограниченные подзадачи и по возможности поручает их субагентам Terra.
- Ведущий ассистент координирует работу субагентов, учитывает общие изменения в репозитории и проверяет интеграцию и результат перед завершением задачи.

## Ветки

- Веди разработку и запускай проверочные сборки из `dev`.
- Переноси изменения из `dev` в `main` через pull request после успешной сборки в GitHub Actions и проверки затронутых сценариев на iPhone. Укажи в pull request ссылку на сборку и результат проверки.
